## Features

- **Three choice buttons:** Rock 🪨, Paper 📄, Scissors ✂️.
- **Random computer choice** using `Math.random()` over an array of the three choices.
- **Correct game logic:** Rock beats Scissors, Scissors beats Paper, Paper beats Rock, identical choices draw.
- **Result display** showing player's choice, computer's choice, and round result.
- **Running score** for Player wins, Computer wins, and Draws.
- **Reset button** clearing scores, round result, and messages.
- **Round counter** incrementing exactly once per round.
- **Responsive** layout for mobile, tablet, and desktop.
- **Accessible** semantic HTML, button labels, keyboard controls, color contrast.

## Technologies

| Technology | Use |
|------------|-----|
| HTML5 | Semantic `main`, `section`, `button`, ARIA attributes (`index.html`) |
| CSS3 | Custom properties, Flexbox, Grid, media queries, focus states (`style.css`) |
| JavaScript | Random selection, game logic, scoring, reset (`script.js`) |
| SVG | Brand mark and favicon (`assets/favicon.svg`) |
| No Frameworks | Zero dependencies |

## How to Run

1. Open the `internship-task-24` folder.
2. Double-click `index.html` — opens in Chrome / Edge / Firefox.
3. Or serve it: `python -m http.server 8000` → http://localhost:8000
4. Or VS Code **Live Server**: right-click `index.html` → **Open with Live Server**.

No install, no build, no dependencies.

Quick syntax check:

```powershell
node --check script.js
```
